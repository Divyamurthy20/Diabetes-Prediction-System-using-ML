# Diabetes-Prediction-System-using-ML
A Diabetes Prediction System built using Machine Learning with real medical data. Includes preprocessing, feature engineering, model training, evaluation, and prediction. Achieves high accuracy and provides a clean, reproducible workflow using Python.

## Features
- Real medical dataset (PIMA Indian Diabetes Dataset or Kaggle dataset)
- Data preprocessing and handling of missing/inconsistent values
- Multiple ML models trained and compared
- Visualizations for insight and correlation analysis
- Notebook-based workflow for clarity and reproducibility
- Prediction script for new user inputs

## Models Used
- Support Vector Machine (SVM)   

## Dataset
- Source: UCI PIMA Diabetes Dataset from Kaggle
- Features include:
  - Pregnancies  
  - Glucose  
  - Blood Pressure  
  - Skin Thickness  
  - Insulin  
  - BMI  
  - Diabetes Pedigree Function  
  - Age  

## Tech Stack
- Python  
- Scikit-Learn  
- Pandas  
- NumPy
- Matplotlib  
- Jupyter Notebook
